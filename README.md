# 💸 Finora – Personal Finance Companion App

Finora is a modern, intuitive, and feature-rich personal finance mobile application built using **Flutter**.  
It helps users track expenses, manage income, analyze spending patterns, and achieve savings goals through a premium "Aura Finance" design system with full Light and Dark mode support.

## ✨ Features

- 💰 **Expense & Income Tracking:** Seamlessly log your daily financial activity.
- 🧾 **Full CRUD Operations:** Add, edit, and delete transactions with ease.
- 🔍 **Interactive Search:** Quickly find past entries using real-time search and filtering.
- 🎯 **Savings Goals:** Set targets and track progress with animated circular indicators.
- ⚡ **No Spend Challenge:** An interactive toggle with streak tracking to build better money habits.
- 📊 **Premium Analytics:** View monthly spending comparisons and category breakdowns on an Insights screen.
- 🌓 **Dual Theme Support:** Switch between Light and Dark modes inspired by the "Astral" design system.

---

## 🛠️ Tech Stack

- **Framework:** Flutter
- **Language:** Dart
- **State Management:** GetX (Reactive architecture)
- **Database:** SQLite (sqflite) with Web Mock support
- **Design System:** Aura Finance (Custom Theme System)
- **Animations:** animate_do & Lottie
